# Beneficiary System

A system for extracting and querying beneficiary information from a public entity's beneficiary database.

## Updating the Beneficiary Seeder

To update the beneficiary seed data:

1. Run the Python script.
2. Copy the generated output.
3. Paste the output into `data-init.sql`.

```python
import random
from faker import Faker

fake = Faker('es_CO')

def generate_mock_data_sql(num_records, filename="data-init.sql"):
    with open(filename, 'w', encoding='utf-8') as file:
        file.write("-- Script generated by Python Mock Data Generator\n")
        
        for _ in range(num_records):
            dni = fake.unique.numerify(text='########')
            names = fake.first_name()
            paternal_surname = fake.last_name()
            maternal_surname = fake.last_name()
            date_of_birth = fake.date_of_birth(minimum_age=18, maximum_age=85).strftime('%Y-%m-%d')
            ubigeo = fake.numerify(text='######')
            
            sql = f"INSERT INTO beneficiaries (dni, names, paternal_surname, maternal_surname, date_of_birth, ubigeo) " \
                  f"VALUES ('{dni}', '{names}', '{paternal_surname}', '{maternal_surname}', '{date_of_birth}', '{ubigeo}');\n"
            
            file.write(sql)
            

if __name__ == "__main__":
    RECORDS_TO_GENERATE = 150 
    generate_mock_data_sql(RECORDS_TO_GENERATE)
```
